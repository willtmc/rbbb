# Support

RBBB is in early development and is not supported for live auctions.

- Use GitHub Discussions for questions, design exploration, and implementation
  help.
- Use the issue templates for reproducible bugs and auction-rule proposals.
- Use private vulnerability reporting for security issues.

The project currently has no paid support channel, uptime commitment, or
response-time service level. A public response in Discussions is not approval
to use the software in production.
