# Scenarios

The `timed-proxy/` directory contains the executable RFC 0001 / RFC 0005 timed
online proxy bidding conformance suite.

Sibling suites live alongside `scenarios/`:

- [`../initial-scheduling/`](../initial-scheduling/) — RFC 0002 initial closing
  schedule planning vectors;
- [`../shared-closing-clock/`](../shared-closing-clock/) — RFC 0003 / RFC 0004
  shared closing clock vectors.
